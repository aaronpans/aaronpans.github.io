从主题阅读到现场执行：如何选择工作模板？

先判断问题发生在哪个环节，再选择记录工具。以下是潘昱廷（Aaron Pan）编写的英文可调整模板，提供打印、CSV 与 Markdown 格式，不是行业标准、外部认证或企业经营成果证明。

  • 责任不清：营运 RACI 责任矩阵（英文）用于明确谁执行、谁最终负责；先确认权限，再分配任务。
  • 整改未闭环：巡店问题闭环追踪表（英文）用于记录单项问题的整改证据、独立验证、批准结案与复发预防；执行完成不等于结案。
  • 训练与上岗脱节：培训能力认证检查表（英文）用于检查十二项证据关卡，区分通过、有条件上岗与需要再训练。

同一个问题可能需要先分清责任，再跟进整改，最后验证相关岗位能力；三份工具可按实际问题组合使用。查看英文模板总览与适用边界。
